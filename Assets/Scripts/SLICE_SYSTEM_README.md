# Система разрезания Slice Art Engine для Unity

## 📋 Обзор

Полная система процедурного разрезания объектов мечом как в Slice Art Engine. Когда меч проходит через объект, он разрезается по плоскости разреза, создавая две отдельные части с правильной геометрией и текстурами.

## 🏗️ Архитектура

### Основные компоненты:

1. **MeshSlicer** - Статический класс для разрезания меша
   - Разделяет меш на две части по плоскости
   - Генерирует cap-геометрию (заплатка на месте разреза)
   - Управляет нормалями и UV координатами

2. **Cuttable** - Компонент объекта, который можно разрезать
   - Размечает объект как режущийся
   - Управляет параметрами разреза
   - Вызывает MeshSlicer при попадании меча

3. **SwordCutPlane** - Определяет плоскость разреза
   - Использует положение и направление меча
   - Правильно ориентирует плоскость разреза
   - Содержит визуализацию для отладки

4. **SwordHit** - Обработчик столкновений меча
   - Отслеживает скорость и импульс меча
   - Вызывает разрезание при столкновении
   - Управляет VFX и логированием

5. **SliceManager** - Глобальный менеджер параметров разреза
   - Централизованное управление поведением разреза
   - Singleton паттерн

6. **ProgressiveSlicer** - Прогрессивное разрушение (Slice Art Engine стиль)
   - Отслеживает траекторию меча
   - Разрушает объект постепенно по мере движения меча
   - Создаёт эффект "прорезания" как в оригинальной игре

## 🎯 Режимы работы

### Обычный режим (Cuttable)
- Разрез всей модели сразу при контакте
- Подходит для простых объектов и быстрого прототипирования

### Прогрессивный режим (ProgressiveSlicer)
- Разрез происходит постепенно по мере движения меча
- Создаёт реалистичный эффект прорезания
- Требует больше настроек, но выглядит аутентично

## ⚙️ Установка и настройка

### Шаг 1: Подготовка объекта меча

1. Создайте или используйте существующий меч в сцене
2. Добавьте компоненты на корневой объект меча:
   - **SwordCutPlane** - для определения плоскости разреза
   - **SwordHit** - для обработки столкновений

3. Настройте ссылки в **SwordCutPlane**:
   - **Blade Tip** - кончик меча (самая дальняя точка)
   - **Blade Base** - основание меча (ближайшая к руке точка)

```
Меч
├── SwordCutPlane (скрипт)
│   ├── Blade Tip → трансформ кончика меча
│   └── Blade Base → трансформ основания меча
└── SwordHit (скрипт)
```

### Шаг 2: Подготовка режущихся объектов

1. На любой объект, который нужно разрезать, добавьте компонент **Cuttable**
2. Убедитесь, что объект имеет:
   - **MeshFilter** - с меш-компонентом
   - **MeshCollider** (или другой коллайдер) - с отмеченным как Trigger

3. В компоненте **Cuttable** установите:
   - **Cross Section Material** - материал для заплатки на месте разреза
   - **Remove Negative Side** (опционально) - удалять ли нижнюю часть после разреза
   - **Remove Delay** (опционально) - задержка перед удалением

### Шаг 3: Настройка SwordHit

В компоненте **SwordHit** настройте:

```
Min Hit Speed = 1.0        # Минимальная скорость для разреза
Cooldown = 0.1             # Время между разрезами одного объекта
Hit VFX = [VFX Prefab]     # Частицы при разрезе (опционально)
Log Level = Hits Only      # Уровень логирования
```

### Шаг 4: Настройка материала для сечения

Создайте материал для заплатки разреза:
- Используйте цвет или текстуру, отличающуюся от основного материала
- Это позволит визуально увидеть место разреза
- Пример: светлый цвет внутренней части объекта

## 🎯 Использование

### Базовый режим (две части остаются)

```
Объект разрезается и создаёт две части:
- Slice_POS - верхняя часть
- Slice_NEG - нижняя часть

Обе части получают Rigidbody и импульс от разреза
```

### Режим с удалением нижней части

В Cuttable установите:
```
Remove Negative Side = true
Remove Delay = 0.5f  # секунды
```

Результат:
- Верхняя часть остаётся и летит от удара
- Нижняя часть удаляется через 0.5 секунды

### Пример: разрезание человека с отделением ноги

```
Человек (GameObject)
├── Body (Renderer + Cuttable)
├── LeftLeg (Renderer + Cuttable)
└── RightLeg (Renderer + Cuttable)

При разрезе через ногу:
1. Нога разделяется на две части
2. Верхняя часть (бедро) получает флаг Remove Negative Side = true
3. Нижняя часть (голень) удаляется
4. Оставшаяся часть летит от удара меча
```

## 🔧 Продвинутые параметры

### Управление физикой разреза

В **MeshSlicer.Create()**:
- **rb.mass** - масса отделённой части (по умолчанию 0.5f)
- **rb.AddForce(dir * 3f)** - сила импульса разреза
- **rb.AddTorque()** - вращение отделённой части

### Оптимизация производительности

1. **Используйте простые меши** - чем меньше вершин, тем быстрее разрез
2. **Настройте collider вариант** - используйте коробку, а не полный меш
3. **Ограничьте максимум разрезов** - установите кулдаун для одного объекта

## 🐛 Отладка

### Визуализация плоскости разреза

1. Выберите объект меча в сцене
2. В компоненте **SwordCutPlane** отметьте "Visualize Plane"
3. В Scene view будут видны:
   - **Красная линия** - направление меча
   - **Жёлтый крест** - плоскость разреза
   - **Голубая линия** - нормаль плоскости

### Включите Debug логирование

В **SwordHit** установите Log Level = "Debug" для подробного логирования:
```
[🔪 SLICE] Object_Name speed=5.42 pos=(10, 5, 3)
```

### Проверка коллайдеров

- Убедитесь, что у меча есть **Trigger коллайдер**
- На режущихся объектах используйте **MeshCollider** или **BoxCollider**
- Оба коллайдера должны быть активны

## 🎮 Советы для лучшего результата

1. **Скорость меча** - минимум 1.0 м/с для разреза
2. **Острый угол** - разрезайте под острым углом для более чистого разреза
3. **Материалы** - используйте контрастный материал для места разреза
4. **VFX** - добавьте частицы крови или искр для полноты

## ❓ FAQ

**Q: Почему объект не разрезается?**
A: Проверьте:
- Скорость меча >= Min Hit Speed
- Объект имеет компонент Cuttable
- На объекте есть коллайдер (Trigger)
- У меча есть SwordCutPlane и SwordHit

**Q: Части разреза летят странно?**
A: Отрегулируйте в MeshSlicer:
- `rb.mass` - увеличьте для менее резкого полёта
- `rb.AddForce(dir * 3f)` - измените множитель силы

**Q: Как разрезать сложный меш?**
A: MeshSlicer автоматически обрабатывает:
- Любое количество вершин
- Любые нормали и UV
- Пересечения плоскости

**Q: Можно ли разрезать анимированные объекты?**
A: Да, используйте SkinnedMeshRenderer - трансформируйте вершины в world space перед разрезом.

## 🎯 Прогрессивное разрушение (Slice Art Engine стиль)

### Как это работает

В **Slice Art Engine** разрез происходит **постепенно** по мере движения меча через объект. Это создаёт эффект "прорезания" объекта, где части исчезают по пути меча.

### Режимы разрушения

1. **Mesh Slicing** — разрез по треугольникам (стандартный)
2. **Voxel Destruction** — разрушение по вокселям (опционально)

### Настройка прогрессивного разрушения

#### Шаг 1 — Включите прогрессивное разрушение

На объекте с компонентом **Cuttable** установите:

```
Use Progressive Slicing = true  ✓
```

Это автоматически добавит компонент **ProgressiveSlicer**.

#### Шаг 2 — Настройте параметры

В компоненте **ProgressiveSlicer**:

```
Slice Depth = 0.1          ← Глубина каждого разреза
Max Slices = 10            ← Максимум разрезов за проход
Min Slice Distance = 0.05  ← Минимальное расстояние между разрезами
Show Slice Points = true   ← Показывать точки разреза в Scene
```

#### Шаг 3 — Убедитесь, что меч имеет тег

Меч должен иметь тег **"Sword"**. Это происходит автоматически через **SwordHit.cs**.

### Как это работает технически

1. **Вход меча** — `OnTriggerEnter` начинает отслеживание траектории
2. **Движение меча** — `OnTriggerStay` добавляет точки разреза по мере движения
3. **Выход меча** — `OnTriggerExit` завершает разрез и применяет все плоскости

### Визуализация

В **Scene View** видны:
- 🔴 **Красные сферы** — точки разреза вдоль траектории меча
- 🟡 **Жёлтые линии** — плоскости разреза
- 🟣 **Пути** — траектория движения меча

### Пример использования

```csharp
// На персонаже (несколько частей)
Персонаж
├── Голова (Cuttable + ProgressiveSlicer)
├── Туловище (Cuttable + ProgressiveSlicer)
├── ЛеваяРука (Cuttable + ProgressiveSlicer)
├── ПраваяРука (Cuttable + ProgressiveSlicer)
├── ЛеваяНога (Cuttable + ProgressiveSlicer)
└── ПраваяНога (Cuttable + ProgressiveSlicer)
```

При проведении мечом через руку — рука разрезается постепенно, создавая эффект прорезания.

### Совместимость

- **ProgressiveSlicer** работает параллельно с обычным **Cuttable**
- Если объект имеет оба компонента, приоритет у ProgressiveSlicer
- Старые объекты без ProgressiveSlicer продолжают работать в обычном режиме

## 📝 Заметки

- Система работает в реальном времени без предварительной подготовки мешей
- Каждый разрез создаёт новые Rigidbody объекты, учитывайте производительность
- Используйте Object pooling для VFX для оптимизации
